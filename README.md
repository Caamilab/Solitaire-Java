# Solitaire em Java

Implementação do jogo Solitaire em Java.

## Pré-requisitos

- Java Development Kit (JDK) 21 ou superior instalado.
- Compilador `javac` e comando `java` disponíveis no PATH.
- Um terminal com suporte à execução de scripts Shell (`.sh`).

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Caamilab/Solitaire-Java.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Solitaire-Java
   ```

3. Execute o script:

   ```bash
   chmod +x run.sh
   ./run.sh
   ```

O script realiza automaticamente a compilação dos arquivos Java e inicia o jogo.

Os arquivos compilados são armazenados no diretório `out/`, criado automaticamente durante a execução.
